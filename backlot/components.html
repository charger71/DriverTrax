Toasts are driven by BL_TOAST.show(msg, "success"|"warn"|"error") — don't build your own.

Don't

  • Hardcode a #hex, pixel, or font-size when a token exists.
  • Use emoji or multi-color icons — single-color SVG <symbol> only.
  • Write a second escaper / formatter / toast — use BL_ESC, BL_FORMAT, BL_TOAST.
  • Reference any driver-app file (../app.css, DT_*). Backlot is self-contained.
  • Ship an icon-only control without an aria-label.
