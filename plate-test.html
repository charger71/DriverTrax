    How to run the test

    • Open on the phone that does lot work, outdoors, in the lighting you actually work in.
    • Tap Start scanning and fill the box with a plate. A read beeps and lands in the list.
    • Judge every read: ✓ if the plate is right, ✎ to type what it actually was. That is what produces the accuracy number.
    • Aim for 30–40 plates across bright sun, shade, dusk, and dirty or angled plates. Include a paper temp tag if the lot has one.
    • Hit Copy JSON and paste it back to me. Median ms and accuracy decide whether this ships in-browser, moves server-side, or gets dropped.

    First run downloads ~4 MB of OCR engine and needs a connection; after that the browser cache serves it. Results are stored only on this device (localStorage) — nothing is written to the fleet. This page is served through the app's service worker, so after a redeploy a hard refresh may be needed to pick up changes.
