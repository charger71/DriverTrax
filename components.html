Disclosure

The one accordion pattern — <details class="disclosure entry-collapse">, no JS needed for open/close itself. Backs every collapsible section in the New Entry form (Conditions, Body damage, Tires, Additional Info) plus the Records filters panel. Give it a unique data-collapse-key and applyEntryCollapseState() in app.js auto-wires per-user open/closed persistence — no extra JS per instance. To hide a whole panel rather than just collapse it (e.g. Body damage / Tires, shown only for their matching Status), toggle .u-hidden on the <details> itself from JS instead of removing it.

Plate & SIPP

Per-VIN identifiers stored on vehicles (plate, plate state, SIPP class code) and rendered by vehicle-info.js. The .vin-id-row mounts into the VIN history header and the New Entry form; the smaller .vin-detail-* tags ride along on VIN lookup rows.

.vin-id-plate and .vin-id-sipp are on the shared .record-status, .badge-* base rule, so they carry the standard badge radius, padding and casing — see Badges. They override only size and fill, stepping up to --font-md so a plate read off a bumper, or a class code across the lot, stays legible. Both fold their second value into the same badge rather than a trailing span: the plate's issuing state becomes a colored NY- prefix (--plate-accent — fixed in both themes, since the plate badge itself is a fixed light surface, same reasoning as --overlay-*), and the SIPP code's expansion follows inside the badge as a .vin-id-sipp-desc span — smaller, regular weight, and off the monospace/tracking treatment, since it's prose rather than a code, and wraps onto a second line rather than trailing off in plain text.

Plate, SIPP and Edit are .vin-id-row's three items — spaced evenly by justify-content: space-between plus flex: 1 1 auto on the two value groups, not forced into equal-width columns (a short plate and a long SIPP expansion shouldn't fight for the same column width). Edit has no eyebrow of its own, so it sits at flex-end — level with the badges' baseline, not stranded up on the label line.

Modal

All app modals use the .users-modal pattern. Toggle .show to open. Status line uses DT_UI.setMessage(el, text, "ok"|"err").

For a plain yes/no, don't build one — await DT_UI.confirm({ title, body, okLabel, danger }) resolves to a boolean and reuses this pattern. Never confirm(): it blocks the main thread, can't be styled, and some WKWebView configurations suppress it outright, which returns false and makes the action silently do nothing.

Map & damage colors

Leaflet divIcon markup and inline SVG fills can't use var(), so JS resolves the token at draw time with DT_UI.cssVar("--token"). Never inline a hex for these — it won't follow the theme. Map markers reuse the semantic and --chart-* tokens; damage marks have their own. 

// Leaflet divIcon
const color = DT_UI.cssVar("--accent");

// Status marker — STATUS_MAP_TOKEN in app.js maps status → token
statusMapColor("CLEAN");   // resolves --accent

// Damage mark

Role colors

Use --role-* tokens whenever you tint by role. Role is gated by DT_AUTH.isManager/isAdmin/isCxr/isDetailer, mirrored on body.is-* classes for CSS-only branching.

Anti-patterns

If you catch yourself writing the right-hand column, stop and reach for the left.

Colors & spacing
Do — use tokens
color: var(--accent);
padding: var(--space-3) var(--space-4);
font-size: var(--font-md);
Don't — hardcode values
color: #00a651;
padding: 12px 16px;
font-size: 16px;
HTML escaping
Do — use DT_ESC
const esc = window.DT_ESC;
el.innerHTML = `<span>${esc(name)}</span>`;
Don't — hand-roll an escape
function esc(s) {
  return s.replace(/</g, "&lt;")...
}
Time / date formatting
Do — DT_FORMAT
DT_FORMAT.time(record.timestamp);
DT_FORMAT.timeAgoOrClock(record.timestamp);
Don't — improvise
new Date(record.timestamp)
  .toLocaleTimeString("en-US",
    { hour: "2-digit", minute: "2-digit" });
Role gating
Do — go through DT_AUTH
if (DT_AUTH.isManager()) {
  /* ... */
}
<!-- Or in CSS: -->
body.is-manager .admin-tools { display: block; }
Don't — read raw role strings
if (profile.role === "manager" ||
    profile.role === "admin") {
  /* drifts when roles change */
}
Toasts
Do — DT_TOAST
DT_TOAST.show("Saved", "success");
DT_TOAST.missing("record");
Don't — alert() or custom popup
alert("Saved");
// or invent a new .my-toast div
Z-index
Do — named scale
z-index: var(--z-modal);
z-index: var(--z-toast);
Don't — magic numbers
z-index: 9999;
z-index: 99998; /* one more than the next thing */
Inline styles in index.html
Do — extend app.css
<div class="field-label">Driver</div>
Don't — reproduce a class inline
<div style="font-size:11px;color:var(--muted);
  text-transform:uppercase;letter-spacing:1px;
  font-weight:700">Driver</div>
